# Panty Dropper

Página da receita do cocktail Panty Dropper. Um único ficheiro HTML, sem dependências de build, com CSS e JavaScript embutidos e a fotografia incluída como data URI.


## Correr localmente

Abre o `index.html` no browser. Não é preciso servidor.

## Estrutura

- `index.html`: a página completa (receita, copo interativo, passos de preparação)
- `.nojekyll`: impede o GitHub Pages de processar o site com Jekyll
- `.github/workflows/deploy.yml`: publica automaticamente em cada push para `main`
